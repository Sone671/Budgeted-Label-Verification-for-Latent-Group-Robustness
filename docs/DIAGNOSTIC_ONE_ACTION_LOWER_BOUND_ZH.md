# 诊断论文的一行动任意预算不可识别下界

## 1. 范围

本结论只研究诊断论文中的一个动作：从带噪训练集中核验至多 (B) 个标签，
然后从相同初始化完整重训。它不引入组审计、两种人工成本或预算分配，因此不
与 `joint_group_label_budget/` 中的另一篇两行动论文重叠。

相比主稿原来的 (B=1)、三原子、(1/3) 下界，这里同时加强四点：

1. 覆盖任意整数预算 (B\ge2)；
2. 覆盖标签反馈后仍可继续选择的顺序随机策略；
3. 两个世界保持完整测试边际 ((X,Y)) 相同，只改变不可见组划分；
4. 在标准无截距 L2-logistic 线性模型中完整重训解唯一，下界可任意接近
   (1/2)。

## 2. 构造

建立两个不相交候选块 (A_0,A_1)，各含 (B) 个不同输入原子。所有候选的
观测训练标签均为 0，真实标签与任意核验反馈均为 1。另设一个始终预测正确的
正标签锚点，在测试分布中重复 (M) 次，以及两个始终正确的负标签锚点。

测试边际在两个世界中逐原子相同：每个候选原子各出现一次且标签为 1，正
锚点质量为 (M)，两个负锚点各出现一次。世界 (P_w) 仅把 (A_w) 指定为
活动弱组；另一个候选块与 (M) 个正锚点组成强正组，两个负锚点分别形成其余
两个非空组。因此四个评估组始终非空，而策略永远看不到组划分。

若查询集合为 (Q)，记

\[
k_w=|Q\cap A_w|,\qquad k_{1-w}=|Q\cap A_{1-w}|.
\]

完整重训后的 WGA（也等于相对未修正模型的 WGA 增量）为

\[
U_w(Q)=\min\left\{\frac{k_w}{B},
\frac{M+k_{1-w}}{M+B}\right\}.
\]

世界知情策略查询整个 (A_w)，取得

\[
V^\star=\frac{M}{M+B}.
\]

## 3. 主定理

### 定理（任意预算的一行动可观测等价下界）

取 (B\ge2) 且

\[
M\ge \max\{B+1,\,B(B-1)\}.
\]

则上述两个世界具有相同的带噪训练集、clean validation、测试边际
((X,Y))、任意标签核验反馈和全部查询前可观测量。对任何允许顺序选择的合法
随机策略 (pi)，

\[
\max_{w\in\{0,1\}}
\mathbb E[\operatorname{Reg}_{P_w}(\pi)]
\ge
\frac{M-B}{2(M+B)}.
\]

该下界是紧的；令 (M\to\infty) 时趋于 (1/2)。

### 证明

因为两个世界中每次核验都返回同一个干净标签 1，任何顺序策略的完整反馈记录
同分布，最终查询集合的分布也相同。对每个确定性 (Q)，

\[
U_0(Q)+U_1(Q)
\le \frac{k_0+k_1}{B}\le1.
\]

随机化保持该不等式。两个世界的 oracle 值均为 (V^\star)，故

\[
\mathbb E[R_0]+\mathbb E[R_1]
\ge 2V^\star-1
=\frac{M-B}{M+B},
\]

至少一个世界达到所述一半下界。

当 (B) 为偶数时，固定在两个块各查询 (B/2) 个样本；当 (B) 为奇数时，
以各 (1/2) 概率在两个块分配
((\lfloor B/2\rfloor,\lceil B/2\rceil)) 或相反数量。在给定的 (M) 条件下，
两个世界的期望 WGA 都恰为 (1/2)，所以最坏 regret 恰为
(V^\star-1/2)，下界可达。

## 4. 标准强凸学习器实现

给每个训练原子分配一个不同的 one-hot 坐标，使用无截距、带正则项

\[
\frac{\lambda}{2}\|\theta\|_2^2,\qquad \lambda>0
\]

的 logistic 回归。每个坐标的目标严格凸且彼此解耦：标签 0 的唯一最优系数为
负，标签 1 的唯一最优系数为正。核验候选只把对应训练标签从 0 改为 1，所以
完整重训恰好只翻转对应测试原子的预测。锚点坐标始终保持正确符号。由 L2 项，
整体目标强凸、全局最优解唯一，构造不依赖查表分类器、初始化或局部极小值。

所有有限测试原子的最优 margin 都严格非零；强凸最优解关于特征矩阵连续。
因此存在一个非零半径，使足够小的非正交特征扰动不改变任何预测符号，WGA
表和下界在该邻域中保持不变。这里声明的是存在性稳定邻域，不声称现实
ResNet 表示位于该邻域。

## 5. 将恢复界中的批量项具体化

主稿定义

\[
\Gamma(Q)=V(Q)-\sum_{i\in Q}V(\{i\}).
\]

若对任意 (S,i,j) 的离散二阶差分满足

\[
|\Delta_i\Delta_j V(S)|\le \eta/N^2,
\]

则按加入元素的顺序展开可得

\[
|\Gamma(Q)|\le
\frac{\eta |Q|(|Q|-1)}{2N^2}.
\]

因此原恢复定理可实例化为

\[
V(Q^\star)-V(\widehat Q)
\le
2B(R\epsilon_p+\epsilon_v)
+\frac{\eta B(B-1)}{N^2}.
\]

这个条件不是自动成立的，但可通过固定协议下的单点/成对修复实验审计；它把
抽象的 (kappa) 变成随预算二次增长、随样本量二次缩小的明确量。最差组切换
会使离散二阶差分变大，正是本文经验上必须单独报告批量稳定性的原因。
