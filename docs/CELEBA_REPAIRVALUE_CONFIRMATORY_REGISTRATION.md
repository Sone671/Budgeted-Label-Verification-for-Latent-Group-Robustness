# CelebA RepairValue-Q prospective follow-up registration

Registered on 2026-08-02 after the exploratory frozen-feature seeds 0--9
screen and before any formal seeds 20--29 end-to-end result was generated or
inspected.  The machine-readable source of truth is
`configs/celeba_e2e_repairvalue_seed20_29.registration.json`.

## Frozen question

For CelebA `Eyeglasses` under uniform 20% label corruption and a 10% label
verification budget, does the legal `RepairValue-Q (tail)` query rule improve
full-retraining WGA over Loss on fresh outer corruption seeds 20--29?

This is a prospective confirmation of a hypothesis generated by the reused
seed 0--9 frozen-feature screen.  It is not an independent discovery.  Seeds
0--9, the TracIn confirmation seeds 10--19, and this follow-up's seeds 20--29
are never pooled.

## Frozen method

RepairValue-Q multiplies NoiseScore by the normalized rank of a first-order
binary label-flip value.  The value target is class-balanced clean-validation
cross-entropy restricted to the highest-loss 20% within each validation
class.  The score uses final-probe penultimate features, freezes and saves the
top-10% query IDs, verifies only those labels, and then retrains all ResNet-50
parameters from the shared seed initialization.

No training group label, clean training label, or test outcome enters query
scoring.  The method is a last-layer query-value proxy followed by full-network
retraining; it is not claimed to be an exact full-network influence estimate
or a universal WGA certificate.

## Primary gate

The primary estimand is

```text
Delta-WGA(RepairValue-Q) - Delta-WGA(Loss)
```

paired within each of the ten seeds.  Both conditions must hold:

1. the lower endpoint of the deterministic 10,000-replicate seed-bootstrap
   95% interval is above zero;
2. at least 8 of 10 paired seed effects are positive.

Absolute Delta-WGA, TracIn-vs-Loss, query precision, and all group-composition
analyses are secondary.  A failed primary gate is retained as a valid null
result and does not permit seed replacement or method/hyperparameter search.
